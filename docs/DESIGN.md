# DESIGN SYSTEM

## 3.1 Style Principles
- **Modern and minimal**: Clean, functional interfaces
- **Professional appearance**: Suitable for hospital/healthcare setting
- **Urgent context**: Red reserved for critical/emergency states only
- **Mobile responsive**: Tested at 375px, 768px, 1440px
- **Accessible**: WCAG 2.1 AA compliant

## 3.2 Typography
- **Primary Font**: Inter (system fallback: -apple-system)
- **Headings**: 700 weight, 24px-32px sizes
- **Body text**: 400 weight, 14px-16px sizes
- **Labels**: 500 weight, 12px-14px sizes

## 3.3 Color Palette
- **Primary**: `#3B82F6` (blue)
- **Critical**: `#EF4444` (red, emergency only)
- **Success**: `#10B981` (green)
- **Warning**: `#F59E0B` (amber)
- **Background**: `#FFFFFF`
- **Surface**: `#F8FAFC`
- **Text**: `#0F172A`
- **Border**: `#E2E8F0`

## 3.4 Key Screens (Target: 10)
1. **Landing page**: Role-based login
2. **Hospital dashboard**: Active emergencies, create request
3. **Emergency request form**: Blood group, component, quantity
4. **Matching results (hero)**: Prioritized resources
5. **Emergency tracking**: Visual timeline
6. **Blood bank dashboard**: Inventory, incoming requests
7. **Blood bank response**: Accept/reject workflow
8. **Donor dashboard**: Available nearby emergencies
9. **Admin dashboard**: System overview, analytics
10. **Emergency command center**: Live map + status (demo screen)
